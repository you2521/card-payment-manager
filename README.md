# カード＆口座引き落とし管理 (Card Payment Manager)

複数のクレジットカードの支払日（引き落とし日）と、紐づく引き落とし銀行口座を一元管理・可視化できるWebアプリケーションです。

---

## 📱 主な特徴

- **完全クライアントサイド動作 (プライベート＆安全)**: データはお使いのブラウザの `localStorage` にのみ保存され、外部サーバーにカード情報等が送信されることはありません。
- **直近の引き落としカウントダウン**: 次に引き落とされるカードと残り日数をひと目で確認可能。
- **2つの表示切り替え**:
  - **支払日順**: 毎月何日にどのカードが引き落とされるかをタイムライン順に把握。
  - **口座別**: 銀行口座ごとにどのカードが紐づいているかをまとめて把握。
- **月間支払日カレンダー**: カレンダー形式で引き落とし予定日を確認。
- **ブランドカラー自動提案**: カード名や銀行名を入力すると、ブランドに合わせたアクセントカラーを自動提案。
- **ダークモード / ライトモード対応**: ワンタップで切り替え可能。
- **スマホ最適化**: スマートフォンでの閲覧・操作に最適化（ホーム画面に追加してアプリ感覚で利用可能）。
